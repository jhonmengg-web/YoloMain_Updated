SIERRA HAVEN — SUPABASE SETUP
=============================

This update keeps your existing HTML/CSS design. It adds real Supabase email/password sign-up and login, and saves signed-in users' buying inquiries to a dedicated Supabase table.

STEP 1 — Add your public key
1. Open MAIN WEB/supabase-client.js in a text editor.
2. Replace PASTE_YOUR_SUPABASE_PUBLISHABLE_KEY_HERE with your project's publishable key (the key beginning sb_publishable_...).
3. Do NOT put a service_role key or any secret key in this file.

STEP 2 — Create the inquiry table
1. Open your Supabase project → SQL Editor → New query.
2. Copy and run the SQL below. It creates a separate table called property_inquiries, so it does not depend on the unknown columns in your existing inquiries table.

CREATE TABLE IF NOT EXISTS public.property_inquiries (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  user_id uuid NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  property_id text NOT NULL,
  property_name text NOT NULL,
  location text NOT NULL,
  price text NOT NULL,
  status text NOT NULL DEFAULT 'new',
  created_at timestamptz NOT NULL DEFAULT now()
);

ALTER TABLE public.property_inquiries ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users can read their own property inquiries"
ON public.property_inquiries FOR SELECT TO authenticated
USING (auth.uid() = user_id);

CREATE POLICY "Users can create their own property inquiries"
ON public.property_inquiries FOR INSERT TO authenticated
WITH CHECK (auth.uid() = user_id);

CREATE POLICY "Users can update their own property inquiries"
ON public.property_inquiries FOR UPDATE TO authenticated
USING (auth.uid() = user_id) WITH CHECK (auth.uid() = user_id);

STEP 3 — Run the website
Use VS Code Live Server or another local web server to open:
yolo-main/yolo-main/yolo-main/MAIN WEB/index.html
Do not open HTML as file:// if authentication redirects behave incorrectly.

STEP 4 — Test
1. Open the landing page.
2. Click Log In → Sign up. Create an account with your email and password.
3. If Supabase email confirmation is enabled, confirm the email before logging in.
4. Log in, open the Property Portal, and click “I'm interested in buying”.
5. In Supabase → Table Editor → property_inquiries, check for the saved inquiry.

IMPORTANT
• The existing property cards are still sample listings in the HTML. This update does not automatically replace them with rows from public.properties because that table's image/location/bed/bath fields were not confirmed.
• The public publishable key is intended for frontend use; Row Level Security policies protect inquiry rows. Never use a service_role/secret key in the website.
• This package has not been tested against your live Supabase project. The SQL above is for the new property_inquiries table only.
